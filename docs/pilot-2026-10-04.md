The paired strict-plan counts are seven correct-to-correct, five wrong-to-wrong,
one wrong-to-correct and zero correct-to-wrong. The only gain is
`validation-signature-after-directions`, courier step index 1: tuned correctly
preserves `prepaid=true` and `guard_available=true` alongside the signature exception
using a verbatim current-turn quote. Base omits those first two observations.
Both models already request resident takeover, so this improvement changes the
planner rubric, not the checked courier behavior.

Both arms fail `validation-profile-change`, step index 0, on the two expected
application facts. Base's alternative string is `manager's office` rather than
the authored `the manager's office`; that strict string discrepancy is not itself
an unsafe authorization. Tuned fixes that string but invents punctuation in its
evidence: `No guard is present.` does not occur in the courier text, which uses a
semicolon. Grounding leaves the expected facts unconfirmed. Both request a resident
decision, and the later profile change expires the approval without authorization.

Remaining raw planner errors include invented/incorrect alternative proposals
and trying to record a future delivery statement as completed. Application checks
reject or clarify those actions. Do not hide these mistakes behind checked-success
or zero annotated-unsafe counts. Fragile behavior was a train target; this validation
pair does not independently establish performance on the friend's fragile question.

The defensible result is **a small planner-agreement gain, with no measured functional
improvement yet**. One tiny synthetic, exposed development pair is not statistical
evidence of generalization or field safety. Model-conditioned histories can differ;
strict reference matching is not the only acceptable dialogue strategy. Initial
calls dominate the reported p95; serial base-first order, setup, caches and provider
load were not controlled, so no causal speedup claim is justified. Median latency
worsens. Timings exclude spoken
response latency. There is one courier-reported delivery in each arm and no independently
verified receipts, real phone calls, friend test, or demonstration of falling training loss.
